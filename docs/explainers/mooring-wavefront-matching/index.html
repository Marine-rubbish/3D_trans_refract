单点系泊与遥感波锋匹配

蓝线是项目 MAT 结果中一条真实保存的派生波锋几何，红点是代码采用的东沙西侧站位：20.8167°N、115.7667°E。它们在地图上靠得很近，但这还不能证明二者属于同一个内波事件。

下面的滑块控制推演时间。灰线代表方案 A 的直线外推，橙线代表方案 B 的空间变速传播，蓝线代表方案 C 由后续影像约束的轨迹。把时间向右拖，三种回答会逐渐分开。

两种仪器看见的不是同一个切面

刚才的地图把两个观测压在同一平面上，藏起了最容易混淆的一层：卫星遥感看见海表亮暗条纹，系泊仪器记录固定位置的水下温度、流速或位移随时间变化。两者都受内波影响，却没有直接测量同一个物理量。

图中的蓝线表示海表可辨的波锋位置，红色竖线表示从海面向下布设的系泊观测列。红色滑块控制展示深度。转到侧面后可以看到，波锋与系泊只有在水平位置和时间同时相遇时，才形成一个待检验的事件对应。

局部几何先给出一个基线

知道两类观测如何相遇后，还需要决定波锋往哪里走。曲线上某一点的局部法向，就是垂直于该点切线的方向。方案 A 把靠近站位的一小段波锋看成近似直线，再沿这条法向传播。

拖动三个空心控制点改变蓝色波锋。橙色箭头只由中点附近的曲线形状决定；远处曲线怎样弯，并不会直接改变这个局部方向。

有了方向，还缺传播速度。这里把局部相速度定义为波锋相位相对水体移动的速度。方案 A 暂时假设短程内速度和方向不变，于是波锋在每一小段时间里移动相同距离。

播放动画，或拖动橙色时间轴。蓝线是遥感时刻的初始波锋，橙线是传播后的预测位置，红点是系泊站。当橙线扫过红点时，模型便得到一个预测到站时刻。

最简单的走时关系是距离除以速度。这里的距离必须沿假定的传播路径计算，速度也必须与同一模态、同一参考系对应。系泊处的局地相速度即使完全准确，也不能自动代表此前整条路径的平均速度。

这个时刻不是一个没有误差的点。速度稍有偏差，传播得越远，走时误差积得越多；方向稍有偏差，横向位置也会越走越散。这里的误差范围表示假设参数下的一阶传播结果，不是本站已经测得的置信区间。

橙色滑块控制传播距离，紫色滑块控制速度与方向误差的相对大小。先只拉大距离，再增加误差，观察紫色包络怎样同时沿传播方向和横向扩张。

用 1.5 m/s 的平均速度、0.15 m/s 的速度标准差和 10° 的方向标准差作演示，30 km 对应约 33.3 分钟走时标准差和 5.24 km 横向标准差；100 km 时增至约 111.1 分钟和 17.45 km。这些数字只说明误差随距离增长。

误差包络只能描述参数不确定性，不能替代错误的传播模型。方案 A 若把一条实际会折转的路径当成直线，即使初始速度完全准确，也可能系统性地错过站位。

紫色滑块控制后续路径的弯曲程度。灰线始终沿初始法向外推，紫线表示一种空间变速下的弯曲路径。把弯曲拉大，观察两条路径在红色站位附近怎样分离。

因此，方案 A 最适合近站、单分支、传播条件变化较小的事件。它的价值是建立透明基线，并暴露误差来自哪里。跨陆坡、绕岛、分支或明显转向的样本，应转入能表达空间变化的模型。

空间变速让波锋发生折射

方案 A 的问题来自整段路径共用一个方向和速度。方案 B 把海域划成二维位置，并给每个位置一个局地传播速度。波锋经过快区和慢区时，各段推进距离不同，原本近似笔直的波锋便会弯曲。这就是这里所说的折射。

第一条滑块控制时间，第二条控制上下方向的速度差。背景中的青色等值线表示速度场的空间变化，橙线是当前波锋，淡线是此前位置。先播放，再增大速度差，观察波锋上下两端如何拉开。

程函方程把刚才的动画压成一句话：位置 x 处的局地速度 c(x)，乘以到达时间场 τ(x) 的空间梯度大小，等于 1。从观测波锋向外求解后，τ 的等值线就是不同传播时刻的预测波锋。

这个模型要求速度为正，并需要从已判定的传播侧初始化。它适合计算首达波锋，却不会凭空知道哪条路径属于南支、哪条属于北支，也不会完整描述反射后的后续到达。

折射仍不能自动解决绕岛后的身份问题。已有东沙研究表明，波锋可沿环礁南北两侧传播，并在背浪面出现复杂的分支形态。普通程函解通常给出首达时间，不能据此宣称已经模拟了反射或非线性重联。

灰色圆形代表只用于教学的岛礁障碍，橙线和紫线分别代表两条候选传播分支。第一条滑块改变入射位置，第二条控制传播时间。拖动入射位置，观察两条路径到达红色站位的先后次序如何改变。

空间速度场之外，背景流还会搬动整条波锋。把波相对水体自身推进的速度称为本征相速度，把模型采用的流动速度称为有效平流速度。两者共同决定波锋相对海底的运动。

播放后依次改变青色流速和方向。橙线只含本征传播，蓝线再叠加背景流。若输入相速度已经包含流效应，就不能再叠加一次；这张图演示的是项之间的关系，不是本站流场反演。

φ 的零等值线代表波锋。第一项描述它随时间变化，青色 Ueff 搬动整条波锋，橙色 cintr 让波锋沿自身法向相对水体推进。若存在垂向剪切，Ueff 还要按相应模态定义，不能直接拿海表流替代。

方案 B 的主要代价也由此出现：它需要水深、同期层化、背景流、模态和初始波锋。输入场的偏差会进入传播结果，因此必须做环境版本记录、网格收敛和参数集合试验。

连续影像可以直接约束位移

方案 B 用环境场预测看不见的传播过程。如果同一波锋在多张遥感影像中连续可见，就可以先把这些位置连成实测轨迹，再向系泊时刻插值或短程外推。这就是方案 C。

三条蓝色短线表示三个成像时刻的波锋，中间的空心点是需要判定的同源位置。拖动它偏离前后两帧形成的趋势，观察蓝色轨迹如何折转。偏离过大时，合理结论可能是“身份不确定”，而不是强行把三帧连起来。

连续观测也有自己的尺度问题。若两次定位误差各为 250 m，并暂时看作独立误差，那么 10 分钟间隔对应的速度标准差约为 0.589 m/s，30 分钟时约为 0.196 m/s。这是教学假设，不是 500 m 影像分辨率自动带来的测量精度。

蓝色滑块控制两景间隔。紫线表示定位误差对速度估计的影响，它随间隔增大而下降；橙线表示波形变化、云遮和跨景错认的相对风险，它会随间隔增大。拖到两端，可以看到间隔并非越短或越长越好。

σx,1 和 σx,2 是两景沿传播方向的定位标准差，Δt 是时间间隔，σĉ 是由位置误差带来的速度标准差。增加 Δt 会压低这一项，却同时给波形演化和身份交换留下更多时间。

因此，方案 C 不能只靠“两景最近”。更稳妥的做法是用三景及以上检查轨迹连续性，保存云遮和太阳耀斑造成的不可观测区域，并把无法确认的轨迹留在歧义状态。

三种传播证据进入同一个关联层

A、B、C 的传播方式不同，但都应输出可比较的证据：预测到站时刻、传播通道与站位的横向距离，以及预测波向与系泊波向的差。把观测值减去预测值，便得到残差。

图的横轴表示标准化时间残差，纵轴表示标准化横向残差，紫色椭圆表示同一误差尺度。第三条滑块控制方向残差。拖动空心候选点，或增大方向差，观察候选怎样离开联合误差范围。

下标 i 表示遥感轨迹，j 表示系泊事件，b 表示传播分支。残差向量依次装入到站时间差、横向距离和方向差；协方差矩阵 Σ 把不同单位换到可比较尺度，J 是无量纲的联合残差大小。

同一份观测不能被重复计权。例如，若走时和所谓“观测速度”都由同一段距离与时差计算，它们并不是两份独立证据。缺少方向或模态观测时，应删除对应项并重新校准，而不是补零。

残差小只说明候选与预测相近。要把它解释成概率，还需要协方差归一化、漏检与误检模型、关联先验和独立校准。没有这些条件时，页面只把结果称为关联分数。

第一条滑块控制最佳候选的证据强度，第二条控制它与次佳候选的分离程度。绿色表示证据和间隔都足够，紫色表示两个候选难以区分，灰色表示没有候选达到接受条件。把两个滑块都向左拉，看看系统为何需要拒配。

选择取决于观测条件

原始资料恢复后，先让 A 在近站样本上建立基线。若遥感稀疏但有同期水深、温盐和流场，用 B 处理空间变速与南北分支。若同一事件在多景中连续可辨，优先使用 C 的实测轨迹，并用它检查 A、B 的传播误差。

A 的最小输入是一景波锋、系泊事件，以及独立的速度和方向信息。它输出局部传播的到站时间与误差范围，工程改动最小，也最容易发现数据口径问题。它不能承担跨岛、分裂或明显转向事件的最终解释。

B 在 A 的基础上增加水深、同期温盐、背景流和模态信息。它输出每个分支的到站时间与站位处方向，能表示空间变速，却也会把环境场、初始波锋和振幅的不确定性带进结果。

C 的核心输入是同一物理波锋在至少两景中的位置，三景及以上更适合检查轨迹连续性。它减少了长距离模型外推，却依赖连续可见条件；云遮、耀斑、断线和波包交换身份都可能让轨迹失效。

无论使用哪一种方法，传播层都应输出预测范围和分支身份，而不是直接宣布匹配结果。关联层再拿这些预测与系泊事件比较，并保存所有候选、拒配原因和使用过的证据。这样才能区分“传播模型错了”和“候选分配错了”。

比较三种方案时，应固定关联规则和共同测试集。在相同接受率下比较正确配对率，或在相同正确配对率下比较接受率；否则，一个大量拒配的方案会显得“更准”，却没有完成同样多的事件关联。

二维程函依据 Jackson（2009）第 2244–2246 页、式（3）、（6）–（10）。本文只采用空间速度场、程函和首达限制，没有把该论文的总体误差转用成 2020–2021 年本站精度。

当前代码入口采用前后各 3 天候选窗、100 km 横向走廊，并由 matchpairs 完成分配。本文提出的不确定度、分支传播和拒配属于目标设计，不应被读成现有实现已经具备。

当前工作区缺少原始遥感、原始系泊记录和完整同期环境场，所以页面没有展示本站正确率。正式验证需要独立同源标注，并按波包和日期整组留出；同一条波锋的多个顶点不能拆成彼此独立的测试样本。

建议先积累至少 200 个可独立判断的波包级案例，再分别报告到站时间误差、正确配对率、可验证样本召回率和拒配率。95% 正确率及其置信区间下限不低于 90% 可以作为初始验收目标，但它是待检验的目标，不是当前结果。

验证样本还应按模态、传播距离、是否跨岛和成像质量分层。参与传播拟合或阈值校准的事件不能再次充当最终测试真值；无法独立判断同源关系的样本应标为歧义，而不是算作正确或错误。

结语

回到开场那条波锋：只有近站、方向和速度近似稳定时，方案 A 的局部外推才足够。跨陆坡或绕岛时，方案 B 用二维速度场表达弯曲和分支。连续影像可用时，方案 C 直接约束位移，并可检验前两种方法。

三种方案不是互相替换的三个按钮。更稳妥的组合是：A 保留为基线，B 处理稀疏遥感下的空间传播，C 在连续可见事件中优先使用；最终都进入同一个允许歧义和拒配的关联层。
